# 分寸合同 · 使用说明

一套会做批注的 AI 法务助手。您递上一份合同，四位"幕僚"依次核阅，把发现的问题像批注一样写在原文旁边；最终定夺权始终在您手里——系统只建议，不擅自放行。

---

## 〇、不登录，先开卷

打开系统即是**产品首页**：一张全屏介绍页，讲清这套系统是谁、怎么运作——大标语之下有执行图自动演示环（四位幕僚沿有向图依次点亮），下方是幕僚介绍卡（悬停任意一张，上方执行图会点亮它的上下游）、双引擎对照、人工把关理念与四个档案入口的分区导航。全程**没有任何登录弹窗打扰**，法规引用、版本对比、协商追踪从首页就能直接点进去逛。默认深靛蓝暗色主题，顶栏右侧随时切亮色，浏览器记得您的选择。

想动手了，点首页顶栏或底部「**进入工作台**」，左侧栏即是完整案头；「开始一次审查」则直达递交页——粘贴文本、填入合同，递交那一刻才需要署名。

需要署名的页面（审查历史、您经办的卷宗详情、规则/模板管理）对访客展示的是**页内引导卡**：一句话说清这一页为什么需要登录，附「登录」按钮——**点它才弹登录层，绝不自动弹出**。登录成功回到原页当场自动出数，不必刷新；页面上已填的内容也不丢。

没有账号怎么办？登录页切到「**注册**」标签，填用户名、邮箱、密码，收 6 位邮箱验证码（5 分钟有效，重发有 60 秒冷却）即可自助开户——默认获得幕僚（reviewer）角色，卷宗归入您自己的租户，与其他注册者互不可见；登录时**用户名或邮箱都能用**（邮箱不区分大小写）。也可由管理员直接发放账号。注意两处角色门槛：规则/模板管理需 admin 或 reviewer，仅有查看权限（viewer）的账号登录后会看到角色说明卡；**知识库入库仅 admin 可操作**（法规库全员共用，写权限收敛以防审查依据被污染），reviewer 可查库。

## 一、开工位：四位幕僚是谁

| 幕僚 | 负责 | 在结果里的样子 |
| --- | --- | --- |
| 条款拆解官 | 把合同拆成一条条条款，抽出金额、期限等要素 | 批注本的骨架（目录与条款正文） |
| 风险猎手 | 找不公平条款、责任陷阱 | 朱色批注（高风险红、中风险橙） |
| 合规法官 | 对照法规查合法性，指出缺失条款 | 石青色批注，附法条依据 |
| 修订顾问 | 给出"改前 → 改后"的具体改写稿 | 青绿色批注，可一键复制 |

每条风险批注还会标明出处：**规则引擎命中**（关键词规则发现）、**大模型推理**（AI 通读发现）、**双引擎分歧**（两方结论不一致，最需要您裁断）。

## 二、递交合同（三种方式任选）

- **案头铺纸**：在首页把文件直接拖进纸面上，松手即进入递交页；
- **合同审查页**：粘贴合同文本，或上传单个文件（支持 PDF、DOCX、TXT）；
- **批量上传**：一次最多 10 个文件，适合月底集中清卷。

递交前先定**审查立场**：买方（甲方）/ 卖方（乙方）/ 中立。选了立场，风险猎手会重点衡量对我方的不利之处，修订顾问的改稿也在合法合规前提下向我方倾斜；中立则公允评估双方。立场记入卷宗，报告封面与批注本都会标明，我方利害在批注中以「（我方）」优先显示。

递交后画面会显示四位幕僚的接力过程（条款拆解 → 风险识别 ∥ 合规检查 → 修订建议）和一份实时"批注工作日志"。审毕自动翻开批注本，中途想走开也不必等——有卷宗需要把关时，浏览器页签会挂上「(N 待把关)」，并弹出桌面通知提醒。

## 三、读懂批注本（核心页面）

**定论纸单（页首）**：一枚落章给出整份合同的定论（高风险/中风险/低风险），旁边是 0–100 的风险评分尺、条款与问题计数，以及幕僚的整体意见。

**批注本（中间纸面）**：合同原文逐条铺在"纸"上，幕僚的发现以彩色批注骑缝附在对应条款之后：

- 原文中**被朱圈圈出的字句**，就是修订顾问建议改动的原文（鼠标悬停可看改动因由）；
- 建议批注里「改前 / 改后」并排呈现，改后可一键复制，直接贴回您的合同；
- 「判断依据」可展开，看到每条结论背后的推理；
- 左侧**目录**按风险着色，点一下即定位到该条款并闪烁提示；
- 条款拆不到位的结论会归入"散页批注"，不会丢。

**逐条表态**：每条批注右下角有「认同 / 存疑」两个钮。您标过"存疑"的条款，稍后提交反馈时会自动预勾选——不用回头翻找。

**幕僚自检**：批注本下方可展开"幕僚自检"清单——交卷前用本卷数据做的确定性核销：四位幕僚是否有环节降级、双引擎判定是否一致、高风险是否配套改稿、必要条款是否缺项；若该卷恰被判分官抽中质检，抽检评分也一并列出。

**谈判要点**：右栏自动把高风险改动整理成一页谈判弹药（哪一条、利害在哪、我方主张），点「带要点入协商」直接进入协商追踪，接着开会。

## 四、行使您的定夺权

- 幕僚拿不准时会停下来：**"幕僚已核毕，数处不敢自专——请您定夺"**，点「入卷把关」填写意见；
- 任何时候都可以「反馈本次审查结果」：给出批准/驳回/需修改的决定、总体评分、指出哪些条款识别错了、哪些漏了；
- 这些反馈**都会进入系统学习**——您纠正得越多，幕僚对贵司口径掌握越准。案头会记下"您已为 N 卷押印"。

## 五、存档与流转

- **PDF / Word 报告**：批注本页右栏「卷宗」里一键导出，报告含定论章、审查立场、条款级明细与法条引用，可直接归档或转发；
- **修订版红线（Word）**：同一卷宗处导出。由条款与建议重建全文，建议删除的文字划朱、建议新增的下划线着青绿，缺项条款附于卷尾——可直接发对方磋商或贴回自己的合同；
- **重新审查**：对同一份合同推倒重来（生成新卷，沿用旧卷立场，旧卷保留）；
- **审查历史**：全部卷宗的台账，按状态与风险一览，点开即回到批注本；
- **删除本卷**：彻底销毁该记录，不可恢复，请先导出报告。

## 六、知识库：让法条成为可查的弹药

侧栏「**知识库**」是审查检索（RAG）的弹药库——把法规条例存成向量索引，审查每一条款时幕僚会先到这里检索相似条文作参考。与「法规引用」页的内置速查（写死的八条关键条文，无需登录）不同，知识库放的是**贵司自己的依据库**：admin 或 reviewer 署名方可进出查阅，而上传、粘贴、移除等入库动作只由 admin 执行。

- **两种入库方式**：上传法规文档（.pdf / .docx / .doc / .txt，≤20MB，PDF 需有文字层），或直接**粘贴一段条文**——系统按「第X条 / 一、 / 1.」自动分块；
- **入库即生效**：切块、向量化、热重载一气呵成，之后的新审查立刻按新库检索；正在嵌入时按钮显示"正在嵌入索引，请稍候…"，属正常耗时；
- **状态卡如实报**：引擎就绪与否、活跃向量块数、已入库文档数、所用嵌入模型；未就绪时会给出处置提示（如开关未开、依赖未装、检索服务未启动），照提示处理即可；
- **检索参考透出**：新卷宗的风险批注「判断依据」、合规批注、修订建议下会出现"**检索参考 · N 条**"折叠区，列出命中的知识库条文原文、出处与相似度——每条结论依据哪部法规的哪一条，当场可审计；
- **移除是软删**：从知识库移除的文档立即退出检索（旧文档的块不再被命中），但历史卷宗里已记录的检索参考原样保留；
- **嵌入模型可换、库自动重建**：服务端可选本地模型（文本不出机）或远程 API（如硅基流动 BAAI/bge-m3，效果更强但被嵌入的条文与检索用的合同条款会发往服务商）；管理员换模型后**重启即可**——系统会拿索引里留存的原文自动重嵌入重建，无需重新上传文档；
- **底层是 Milvus 检索服务**：向量库存放在服务端自部署的 Milvus（一条 Docker 启动命令即可就绪），贵司内网部署则检索数据不出网；您在界面上无需感知"哪种库"——状态卡会如实报告服务是否正常，未启动时按提示交管理员处置即可；
- **开关在服务端**：若状态卡显示"RAG_ENABLED 开关未打开"，上传入库照常落盘（先囤库后开闸），由管理员在服务端 `.env` 打开后重启即启用；显示缺 `SILICONFLOW_API_KEY` 或 Milvus 服务未启动同理，由管理员处置后重启。

## 八、常见问题

**Q：为什么有的卷宗里没有"大模型推理"的批注？**
AI 推理需要服务端配置大模型密钥；未配置或调用失败时系统自动降级，只跑关键词规则，页面会在"质量提示"中如实说明降级环节。

**Q：审查要多久？**
在线审查一般十几秒到几分钟，取决于合同长度；批量卷宗排队处理，案头"正在核阅"计数实时可见。

**Q：改规则/模板会影响旧卷宗吗？**
不会。历史卷宗保存的是审查当时的结论；规则改动只对之后的新审查生效。

**Q：数据安全吗？**
卷宗存放在您自部署的数据库内，按账号租户隔离。请注意：启用 AI 推理时，合同文本会发送给所配置的大模型服务商；启用远程嵌入（`EMBEDDING_SOURCE=api`）时，知识库条文与检索用的合同条款也会发往嵌入服务商；若贵司有保密要求，请选用私有化部署或合规的模型接入，纯规则模式 + 本地嵌入则完全本地运行（Milvus 若部署在自有基础设施上，数据不出内网）。

**Q：登录不了？**
用户名或注册邮箱都可以登录（邮箱不区分大小写）。没有账号可在登录页「注册」标签自助注册；收不到验证码多因管理员未配 SMTP，或该邮箱已注册（请直接登录）。忘记密码需由管理员在后台重置（暂无自助找回）。登录状态过期后，点击写操作或调卷会自动弹回登录层，重新署名即可续做，不必刷新页面。

**Q：不登录能看到什么？**
全程都能看：首页是完整的产品介绍（执行图演示、四位幕僚、双引擎说明），法规引用、版本对比、协商追踪直接可逛，审查页也能先填内容。递交、卷宗、把关、导出、规则/模板/知识库需要署名——访客会见到页内引导卡，点卡上的登录钮才弹层，登录后当场续做、自动出数，不丢已填内容。
